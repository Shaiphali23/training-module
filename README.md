# 📖 About

Chiku Cabs Training Platform is an AI-powered Learning Management System (LMS) built to train customer support executives, sales teams, drivers, and operations staff.

The platform provides structured learning modules, quizzes, AI voice practice, live assessments, and progress tracking to ensure every employee is fully trained before handling customers.
